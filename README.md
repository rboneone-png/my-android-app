# 股票記帳

記錄台股與美股的 Android App：交易與股利紀錄、即時股價、損益計算、資產配置、質押管理、股價通知、圖表與 Excel 匯出／匯入。

- 版本：2.17.2
- 系統需求：Android 8.0 以上
- 資料只存在手機裡，可自行備份到 Google 雲端硬碟

## 安裝

1. 到 [Releases](https://github.com/rboneone-png/my-android-app/releases) 下載最新的 `StockRecord-x.x.x.apk`
2. 在手機上點開檔案安裝；第一次會要求允許「安裝未知來源的應用程式」
3. 之後的新版本可以直接覆蓋安裝，手機裡的資料會保留

> 每次推送程式碼，GitHub Actions 也會自動編譯：在 **Actions** 分頁點最新的 **Build APK**，下方 Artifacts 的 `stock-record-release` 是正式版、`stock-record-debug` 是測試版。

## 功能與使用方式

### 登入與帳號
- 第一次開啟時在「新增」建立帳號；可建立多個帳號，每個帳號的資料、設定、備份完全分開
- 登入方式可選密碼、指紋或臉部（密碼為備用）；離開 App 超過 5 分鐘需重新登入

### 持股總覽（持股）
- 台股／美股切換；累積損益、持股市值、持股成本、股息收入、持股日損益、未實現損益、已實現損益
- 庫存股：股價與漲跌、成本均／買均、總損益（預扣賣出費用）；點一下看明細（含今日損益：舊持股 = 股數 × (現價 − 昨收)、今天買進的股數 = 股數 × (現價 − 買進成本)，整數，紅漲綠跌灰平），**長按拖曳**調整順序；庫存股依**股票分類**分組（原型、正二、類現金、個股、其他、未分類，依序排列），每組標題顯示檔數與該組總損益，點標題展開／收合（預設全部收合，台股、美股各自記住）；長按拖曳排序只能在同一組內調整；「已出清」也可點標題展開／收合（預設收合）
- 右上角：**紀錄**（交易與股利紀錄，依日期分組，點日期展開／收合，預設收合）、**隱藏**金額、**圖表**、手動更新股價
- 股價每 30 秒自動更新（可在設定調整）；右下角 **+** 新增買賣或股利

### 帳務管理
底部導覽列的「帳務」進入（原本通知的位置），單一新台幣帳戶（不分台股、美股）：
- **存入現金**、**領出現金**：輸入金額、日期（預設今天，年月日下拉選擇）與備註
- 「存入與領出紀錄」可展開／收合（預設收合），點一筆可修改或刪除
- 當日賣出金額（B）：今天所有賣出股票的成交金額總和（股數 × 成交價）
- 當日買進金額（C）：今天所有買進股票的成交金額總和
- 當日帳務（D）= B − C
- 當日質借金額：今天新增的質借金額
- 當日股利：今天入帳的現金股利（實際入帳，已扣除代扣稅與匯費；股票股利不計）
- 當日貸款金額：今天是貸款繳款日時，自動扣款的每月繳款
- 當日質借歸還金額、當日質借歸還利息：今天歸還質借時，本金與利息一起扣除
- 當日可用餘額（A）= 存入現金 − 領出現金 + 帳務累計 + 質借金額累計 + 股利累計 − 貸款累計 − 質借歸還累計（本金＋利息）
  - 存入、領出、帳務、質押、股利都是歷來累計，前幾天的買賣、質押與股利會留在餘額裡，隔天不會只剩現金
  - 帳務累計 = 歷來每一天（賣出 − 買進）的總和，其中今天的部分就是當日帳務 D
- **貸款**：「新增貸款」輸入貸款型式（房貸／信貸／車貸／其他）、貸款金額、年利率（%）、貸款期數（每月一期）、已繳期數（預設 0）、繳款日（每月幾號）；每月繳款由系統自動計算（本息平均攤還：貸款金額 × 月利率 ÷ (1 − (1 + 月利率)^−期數)，月利率 = 年利率 ÷ 12，四捨五入到整數）
  - 繳款日當天自動從可用餘額扣款，顯示為「當日貸款金額」，之後留在「貸款累計」；從建立日「之後」的第一個繳款日開始扣，繳滿期數停止；該月沒有那一天（如 31 日遇 2 月）改在月底扣
  - 貸款清單可展開／收合（預設收合），點一筆可修改或刪除；資料會包含在備份與還原中；資產配置的「現金」也會跟著扣掉貸款
- 美股買賣與美股股利以目前的美元兌台幣匯率換算成台幣（過去的也用同一個匯率）；所有金額四捨五入到整數
- 金額不含手續費與證交稅；存入、領出紀錄會包含在備份與還原中

### 觀察
分成三個分頁：
- **觀察股票**：新增想追蹤的股票（不必持有），顯示股價、漲跌、漲跌幅
- **指數**：大盤指數與台指期，顯示點數、漲跌、漲跌幅；按「新增指數」從清單選擇
  - 可選台灣加權指數、台指期近月、S&P 500、道瓊工業指數、那斯達克綜合指數、那斯達克 100 指數、費城半導體指數
  - 台指期近月：期交所即時報價，日盤與夜盤自動取最新成交；近月合約到期後自動換成下一個月
- **股票漲跌**：新增股票（或指數）後顯示「2年最高價、現價、漲跌幅」（台指期沒有歷史資料，不支援）
  - 最高價：近 2 年的最高股價（自動從網路抓取，每天更新一次；盤中創新高時以現價為準）
  - 漲跌幅 = 現價 ÷ 最高價 × 100%
- 三個分頁可以用手勢左滑／右滑切換（也可以點上方標籤）；設定 → 手勢切換可關閉
- 每個分頁都可長按拖曳調整順序，點一下移除

### 股票分割
- 持股總覽右下角「＋」→「股票分割」（在「新增股利」下方）→ 先列出庫存股清單，選要分割的股票 → 設定：
  - 股票：依選擇帶入；暫停交易日、恢復交易日：下拉選日期；每股拆分：1 股分成幾股（1 分 5 請輸入 5，2 以上的整數）
  - 暫停交易日必須早於恢復交易日，否則提示「設定錯誤」
- **到了恢復交易日自動調整**（每次打開 App、畫面刷新與背景檢查時確認）：這檔股票在恢復交易日**之前**的買賣、股利、質押股數、通知價格，換算成分割後的股數與價格（股數 × 倍數、每股價格 ÷ 倍數，金額與總成本不變）
- 清單下方「已設定的股票分割」可看待執行／已執行；待執行的可修改或刪除，已執行的可「還原這次分割」（調回分割前）
- 分割資料包含在備份與還原中

### 資產配置（配置）
- 為每檔持股設定分類：原型、正二、類現金、個股、其他
- 持股清單依分類分組（尚未分類、原型、正二…），點分類標題可展開／收合（預設收合），標題顯示該組的市值小計
- A 原型、B 正二、C 類現金、D 現金（自動帶入帳務管理的「當日可用餘額」，不用手動輸入）、E 個股、F 其他
- 總資產 = A + B + C + D + E + F（個股與其他不計入曝險）；曝險 = A + 2 × B，並顯示曝險比例
- 美股以即時匯率換算台幣；未分類的持股會提醒設定
- 頂端兩個分頁：**資產配置**、**CLEC退休投資策略**

#### CLEC 退休投資策略分頁
- A 一年生活費：自己輸入；B 配置方式：下拉選單（703、613、523、433、343、253、163、073，只能選不能輸入），三碼依序是原型指數：正二槓桿：類現金（各碼是幾成，703 = 70%／0%／30%）
- C 曝險（Beta）= 第一碼數值 + 2 × 第二碼數值（703 → 0.7；433 → 0.4 + 2 × 0.3 = 1.0）
- D 金融資產 = F + G + H；F 指數ETF = 原型市值；G 正二ETF = 正二市值；H 類現金 = 類現金市值 + 現金
  - F、G、H **預設自動帶入**資產配置頁的數字，也可以直接**手動修改**（欄位出現「自動」按鈕，按下恢復自動）；手動數值會記住並包含在備份與還原中
  - F、G、H 的輸入格縮小，右側顯示**佔比**：F 佔比 = F ÷ D × 100%、G、H 同理，小數一位（第二位四捨五入）；D 為 0 時顯示 --
  - E 曝險金額 = 資產配置頁的曝險；F 或 G 手動修改後，E 改為 F + 2 × G
- I 幾倍年生活費 = D ÷ A，小數一位（第二位四捨五入）
- J 現況建議配置：依 I 對照下表，並在對照表中標示目前落在哪一列
- 依 J 的建議配置，把金融資產 D 分成三項建議數值：建議指數ETF = D × 原型%、建議正二ETF = D × 正二%、建議類現金 = D × 類現金%（四捨五入顯示到整數；沒填一年生活費時顯示 --）

### 質押
- 質押頁按「新增質押」，先進入**選擇質押股票**清單，顯示股票、可質押股數、股價、可質押市值
  - 可質押股數 = 持股 − 已質押股數，再無條件捨去到 1,000 股的倍數（例如 23,211 股只算 23,000 股）；不足 1,000 股的股票不列入
  - 可質押市值 = 可質押股數 × 股價
  - 「包含正二」關閉時，清單不顯示正二（清單上也可直接切換）
  - 點選股票進入**質押設定**
- 質押設定：
  - 股票代碼（可修改）、股票名稱與股價自動帶入、可質押股數與可質押市值依清單算法帶入
  - 質押股數：須為 1,000 股的倍數，且不可超過可質押股數（預設帶入全部可質押股數，可改小）
  - 質借金額：須為 1,000 的倍數（5,100、5,010、5,001 這類會顯示錯誤，請重新輸入）
  - 維持率 = 質押股數 × 股價 ÷ 質借金額，**最低 166%**，低於以紅色警示且無法新增
  - 質押利率（%，年利率）
  - 質押率 = 質借金額 ÷ 可質押市值，**最高 60%**，超過以紅色警示且無法新增
  - 利息預估 = 質借金額 × 質押利率（年）
  - 日期：預設今天，年／月／日下拉選擇
- 點質押清單中的紀錄可修改金額、利率與日期，或刪除（股票與質押股數固定）
- 質押清單依質押月份分組，點月份可展開／收合；月份列顯示該月的筆數、利息、質借金額與維持率
- **質借歸還**：質押頁右下角的「質借歸還」按鈕 → 跳出質押清單 → 選一筆 → 進入歸還設定（帶入股票、質押股數、質借金額、利率、質押日期等與質押設定相同的參數），選歸還日期（不早於質押日、不晚於今天）
  - 利息 = 質借金額 × 年利率 × 質押天數 ÷ 365，質押天數 = 質押日到歸還日（質押當天歸還為 0 天），四捨五入到整數
  - 歸還時，**質借金額與利息一起從帳務管理的可用餘額扣除**（歸還日當天顯示為「當日質借歸還金額」「當日質借歸還利息」，之後留在「質借歸還累計」）
  - 歸還後這筆不再計入質借總金額、質押維持率與已質押股數（股數回到可質押股數）；已歸還的紀錄收在清單下方的「已歸還」（預設收合），點一筆可修改歸還日期或取消歸還
- 維持率 = 質押股數 × 股價 ÷ 質借金額 × 100%；質押維持率 = 質押總市值 ÷ 質借總金額 × 100%
- 可質押股票總市值可切換是否「包含正二」
- 維持率顏色：≥ 250% 綠、175%～250% 黃、< 175% 紅（導覽列「質押」字同步變色）；低於 175% 時發出通知

### 月報酬
分成兩個選項，台股／美股分開計算：
- **月報酬**：月曆顯示每天的損益與報酬率、每週與整月合計；可切換月份
- **資產走勢**：每個月底的持股市值（紅色長條）與持股成本（折線），可看近 12／24 個月或全部；下方列出每月的市值、成本與未實現損益
  - 持股市值 = 月底持有股數 × 月底最後交易日收盤價（本月為最新股價），不含現金，已賣出的股票不計入
  - 台股以萬元為單位，美股以美元為單位

### 通知
- 從「設定」→「股價通知」進入（不在底部導覽列）
- 為特定股票設定條件，達到時發出手機通知：
  漲幅／跌幅 ≥ X 元、漲幅／跌幅 ≥ X%、漲到 X 元（突破價）／跌到 X 元（跌破價）
- 條件文字中「上漲」以紅色、「下跌」以綠色顯示
- 同一條件每個交易日只通知一次；App 關閉時約每 15 分鐘在背景檢查（省電模式可能延後）

### 新增買賣的股數
- 股數欄右緣有上下箭頭，每按一次增加或減少 1,000 股（1 張），最少到 0；也可以直接輸入任意股數

### 賣出股數檢查
- 新增或修改買賣時，會逐日檢查股數：任何一天的賣出股數超過當天持有的股數（之前持有 + 當天買進 + 配股），就顯示紅字「股數不足」並無法儲存
- 補登過去日期的賣出也會檢查「那一天」有沒有足夠的股數，不是只看現在的總持股
- 同一天先買再賣（當沖）可以
- 修改或刪除買進，若會讓之後的賣出股數不足，同樣不能儲存或刪除

### 圖表與匯出
- 圖表：持股比例圓餅圖、最近 12 個月已實現損益與股利長條圖
- 匯出／匯入 Excel（設定 → 匯出／匯入 Excel）：
  - 匯出：交易紀錄、持股、股利、已實現損益、每月損益、質押共 6 個工作表（交易紀錄多一欄「稅別」：一般／ETF／當沖，台股才有）
  - 匯入：讀「交易紀錄」「股利」兩個工作表（格式同匯出），依**標題列名稱**對應欄位，順序可以不同；必要欄位——交易紀錄：日期、市場、代號、買賣、股數、成交價；股利：發放日、市場、代號，且現金股利或配股股數至少一項。選填：名稱、手續費、交易稅、稅別、備註（股利另有扣稅／健保、匯費）
  - 手續費、交易稅、股利扣稅**留空**時，依設定頁的費率自動計算；明確填 0 就是 0。日期可用 2026-11-10、2026/11/10、20261110 或 Excel 日期；市場填「台股」「美股」；買賣填「買進」「賣出」；台股代號被 Excel 存成數字（50）時自動補成 0050
  - 匯入方式：**新增**（加到現有資料，和現有紀錄完全相同的略過，同一個檔案匯入兩次不會重複）或**取代**（先刪除現有所有買賣與股利）；讀不懂的列會列出列號並略過；匯入後若賣出超過持有股數，整批不匯入
  - 持股、已實現損益、每月損益、質押這幾個工作表是計算結果，匯入時不讀

### 外觀
- **配色模式**：設定 → 配色模式，可選「淺色模式」（預設）或「深色模式」，立即生效，登入頁也套用；不再跟著系統的深色設定
- 固定的品牌配色（深藍為主色，不隨桌布變色），淺色與深色模式各一組；頁面是淡灰藍底，內容放在白色圓角卡片上
- 頂欄為淡藍底、深藍粗體標題；總覽類頁面（持股總覽、資產配置、質押、帳務）的摘要用淡藍漸層的卡片；主要按鈕與「＋」浮動按鈕為深藍
- 金額與百分比使用等寬數字，上下對齊；圓角加大、陰影輕微；紅漲綠跌的顏色不變

### 設定
- 設定頁只顯示各項目的標題，點標題展開或收合（預設全部收合）
- 登入方式、股價自動刷新秒數、手續費折扣（預設 0.28）與最低手續費、美股手續費與股利預扣稅率
- **備份／還原**：存成檔案，可選擇存到 Google 雲端硬碟，不需額外設定
- **自動備份**：設定頁選一個備份檔（建議存到 Google 雲端硬碟），App 會依週期自動寫入同一個檔案；不需要 Google Cloud 設定
- 匯出／匯入 Excel、登出
- **手勢切換**：設定 → 手勢切換，「左右滑動切換分頁」開關（預設開啟）。開啟時，觀察（三個項目）、持股／月報酬／圖表的台股／美股、資產配置的「資產配置／CLEC退休投資策略」都可以左滑／右滑切換；月報酬頁依序在「台股月報酬 → 台股資產走勢 → 美股月報酬 → 美股資產走勢」之間切換；紀錄頁可在「買賣紀錄／股利紀錄」之間切換；關閉後只能點上方標籤
- **操作手冊**：設定 → 操作手冊，App 內直接看圖文說明，兩指縮放、單指拖曳、連點兩下切換 1／2 倍（內建 PDF，`app/src/main/assets/manual.pdf`，與 `docs/操作手冊.pdf` 同一份，更新時兩處一起換）
- **關於**：設定 → 關於，顯示版本與本版修改處（讀取打包進 App 的 `docs/release-notes/v<版本>.md`，所以每個版本都要有對應的說明檔）

## 計算方式

| 項目 | 說明 |
|---|---|
| 台股手續費 | 成交金額 × 0.1425% × 折扣，無條件捨去，最低 20 元 |
| 台股證交稅 | 賣出時：一般股票 0.3%、ETF 0.1%（00 開頭自動帶入）、當沖 0.15% |
| 已實現損益 | 平均成本法，扣除手續費與交易稅 |
| 未實現損益 | 市值 − 預估賣出手續費與證交稅 − 成本 |
| 成本均／買均 | 成本均扣除持有期間股息；買均為實際買進成本（含手續費） |
| 股利 | 現金股利總額 = 每股股利 × 發放日當天持有股數（自動帶入，可手動修改；四捨五入到小數兩位）；台股單筆 2 萬元以上自動帶入二代健保 2.11%；美股預設預扣 30% |
| 每日報酬 | 收盤市值變化 − 買進金額 + 賣出淨收入 + 股利入帳；週／月報酬率以每日連乘。今天的數字用即時報價計算，與持股頁的「持股日損益」相同 |

即時股價與匯率來源：
- 台股上市、美股、美元匯率：Google 財經（即時）
- 台股上櫃：臺灣證券交易所即時報價（Google 財經沒有上櫃股票）
- 以上抓不到時自動改用 Yahoo Finance（台股約延遲 20 分鐘）
- 股票名稱、歷史日線（月報酬）、2 年最高價：Yahoo Finance

以上皆為網站使用的非官方介面，格式可能變動。

## 新安裝時用備份檔登入
換手機或重新安裝後，登入頁的「備份檔登入」分頁：選舊手機備份的檔案（可從 Google 雲端硬碟選），輸入原本的密碼，帳號與資料一起還原。備份檔內含密碼的加鹽雜湊值（不含明碼）；1.14.0 之前產生的備份沒有帳號資料，需先「新增」同名帳號再到設定頁還原。請妥善保管備份檔。
