# 股票記帳

記錄台股與美股的 Android App：交易與股利紀錄、即時股價、損益計算、資產配置、質押管理、股價通知、圖表與 Excel 匯出。

- 版本：1.0.0
- 系統需求：Android 8.0 以上
- 資料只存在手機裡，可自行備份到 Google 雲端硬碟

## 安裝

1. 到 [Releases](https://github.com/rboneone-png/my-android-app/releases) 下載最新的 `StockRecord-x.x.x.apk`
2. 在手機上點開檔案安裝；第一次會要求允許「安裝未知來源的應用程式」
3. 之後的新版本可以直接覆蓋安裝，手機裡的資料會保留

> 每次推送程式碼，GitHub Actions 也會自動編譯：在 **Actions** 分頁點最新的 **Build APK**，下方 Artifacts 的 `stock-record-release` 是正式版、`stock-record-debug` 是測試版。

## 功能與使用方式

### 登入與帳號
- 第一次開啟時在「新增」建立帳號；可建立多個帳號，每個帳號的資料、設定、備份完全分開
- 登入方式可選密碼、指紋或臉部（密碼為備用）；離開 App 超過 5 分鐘需重新登入

### 持股總覽（持股）
- 台股／美股切換；累積損益、持股市值、持股成本、股息收入、持股日損益、未實現損益、已實現損益
- 庫存股：股價與漲跌、成本均／買均、總損益（預扣賣出費用）；點一下看明細，**長按拖曳**調整順序
- 右上角：**紀錄**（交易與股利紀錄）、**隱藏**金額、**圖表**、手動更新股價
- 股價每 30 秒自動更新（可在設定調整）；右下角 **+** 新增買賣或股利

### 觀察
- 新增想追蹤的股票（不必持有），顯示股價、漲跌、漲跌幅
- 長按拖曳調整順序，點一下移除

### 資產配置（配置）
- 為每檔持股設定分類：原型、正二、類現金、其他
- A 原型、B 正二、C 類現金、D 現金（自行輸入）、E 其他
- 總資產 = A + B + C + D + E；曝險 = A + 2 × B，並顯示曝險比例
- 美股以即時匯率換算台幣；未分類的持股會提醒設定

### 質押
- 記錄台股質押：股票代碼（名稱自動帶入）、質押股數、金額、利率、日期
- 利息支出 = 質押利率 × 質押金額（年）
- 維持率 = 質押股數 × 股價 ÷ 質押金額 × 100%；質押維持率 = 質押總市值 ÷ 質押總金額 × 100%
- 可質押股票總市值可切換是否「包含正二」
- 維持率顏色：≥ 250% 綠、175%～250% 黃、< 175% 紅（導覽列「質押」字同步變色）；低於 175% 時發出通知

### 月報酬
- 月曆顯示每天的損益與報酬率、每週與整月合計；可切換月份與台股／美股

### 通知
- 為特定股票設定條件，達到時發出手機通知：
  股價漲幅／跌幅（元）、漲幅比率／跌幅比率（%）大於等於設定值、股價高於等於／低於等於設定值
- 同一條件每個交易日只通知一次；App 關閉時約每 15 分鐘在背景檢查（省電模式可能延後）

### 圖表與匯出
- 圖表：持股比例圓餅圖、最近 12 個月已實現損益與股利長條圖
- 匯出 Excel：交易紀錄、持股、股利、已實現損益、每月損益、質押共 6 個工作表

### 設定
- 登入方式、股價自動刷新秒數、手續費折扣（預設 0.28）與最低手續費、美股手續費與股利預扣稅率
- **備份／還原**：存成檔案，可選擇存到 Google 雲端硬碟，不需額外設定
- **自動同步**：定時自動備份到 Google Drive，需先完成 [Google Cloud 設定](docs/google-cloud-setup.md)
- 匯出 Excel、登出

## 計算方式

| 項目 | 說明 |
|---|---|
| 台股手續費 | 成交金額 × 0.1425% × 折扣，無條件捨去，最低 20 元 |
| 台股證交稅 | 賣出時：一般股票 0.3%、ETF 0.1%（00 開頭自動帶入）、當沖 0.15% |
| 已實現損益 | 平均成本法，扣除手續費與交易稅 |
| 未實現損益 | 市值 − 預估賣出手續費與證交稅 − 成本 |
| 成本均／買均 | 成本均扣除持有期間股息；買均為實際買進成本（含手續費） |
| 股利 | 台股單筆 2 萬元以上自動帶入二代健保 2.11%；美股預設預扣 30% |
| 每日報酬 | 收盤市值變化 − 買進金額 + 賣出淨收入 + 股利入帳；週／月報酬率以每日連乘 |

股價與匯率來源為 Yahoo Finance（非官方 API），台股可能有延遲。

## 開發資訊

- 架構說明：[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Kotlin、Jetpack Compose（Material 3）、Room、WorkManager
- 本機建置：`./gradlew assembleRelease`（輸出於 `app/build/outputs/apk/release/`）
- 單元測試：`./gradlew testDebugUnitTest`
- 正式版使用 R8 縮減與最佳化；簽章金鑰 `app/debug.keystore` 公開於儲存庫，方便各版本直接覆蓋安裝。若要上架 Google Play，需改用私密金鑰（舊版需移除後重裝，可先備份再還原）
- 發布新版本：修改 `app/build.gradle.kts` 的 `versionName`／`versionCode`，新增 `docs/release-notes/v<版本>.md` 後推送到 main，GitHub Actions 會自動建立 Release 並附上 APK（推送 `v*` 標籤也可以）
