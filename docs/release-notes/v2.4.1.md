# 股票記帳 2.4.1

## CLEC 退休投資策略：F、G、H 可手動修改

- F 指數ETF、G 正二ETF、H 類現金，預設**自動帶入**資產配置頁的數字（原型市值、正二市值、類現金市值 + 現金）
- 三個欄位都可以直接輸入數字手動修改；改過之後欄位右側出現「自動」按鈕，按下就恢復自動帶入，欄位下方會顯示原本的自動值供對照
- 手動數值會記住（重開 App 還在），也會包含在備份與還原中；欄位清空視為 0
- D 金融資產 = F + G + H、I、J 都會用修改後的數字計算
- E 曝險金額：沒有手動修改時仍是資產配置頁的曝險金額；F 或 G 手動修改後，改為 F + 2 × G

## 安裝
直接覆蓋安裝，資料會保留。
