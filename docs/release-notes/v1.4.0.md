# 股票記帳 1.4.0

## 觀察新增「台指期近月」

- 新增觀察時選「指數／期貨」→「台指期近月」
- 期貨交易所即時報價，日盤與夜盤自動取最新成交；漲跌以前一個結算參考價計算
- 近月合約到期後，自動換成下一個月合約，不用重新設定
- 台指期沒有歷史日線，因此不能加入「股票漲跌」（2 年最高價）

## 月報酬頁新增「資產走勢」

- 月報酬頁上方可切換「月報酬」與「資產走勢」，台股／美股分開
- 每個月底的持股市值（紅色長條）與持股成本（折線），可選近 12 個月、近 24 個月或全部
- 台股以萬元為單位，美股以美元為單位
- 圖下方列出每月的持股市值、持股成本、未實現損益
- 持股市值 = 月底持有股數 × 月底最後交易日收盤價（本月為最新股價），不含現金，已賣出的股票不計入
