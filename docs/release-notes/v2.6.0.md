# 股票記帳 2.6.0

## 質押新增「質借歸還」

1. **按鈕與選擇清單**：質押頁右下角新增「質借歸還」按鈕（有質押中的紀錄才會出現），按下後跳出質押清單，每筆顯示質押日、股數、質借金額、利率，以及「質押至今幾天、利息約多少」；點一筆進入歸還設定
2. **歸還設定**：帶入這筆質押的參數（股票代碼與名稱、股價、質押股數、質借金額、利率、維持率、質押日期，與質押設定相同），選歸還日期（不早於質押日、不晚於今天），系統顯示質押天數、利息、歸還合計
3. **利息以質押天數計算**：利息 = 質借金額 × 年利率 × 質押天數 ÷ 365，質押天數 = 質押日到歸還日（質押當天歸還為 0 天），四捨五入到整數元
4. **帳務扣除**：歸還後，質借金額與利息一起從帳務管理的可用餘額扣除。歸還日當天顯示「當日質借歸還金額」「當日質借歸還利息」，之後留在「質借歸還累計（本金＋利息）」；當日可用餘額 = 存入 − 領出 + 帳務累計 + 質借金額累計 + 股利累計 − 貸款累計 − 質借歸還累計
5. **相關數字同步變動**：歸還後這筆不再計入質借總金額、質押維持率、利息總支出；質押的股數回到可質押股數（可以再質押）
6. **已歸還清單**：質押清單下方新增「已歸還」（預設收合），顯示質押日 → 歸還日（天數）、質借金額、利息與已付利息合計；點一筆可修改歸還日期，或「取消歸還」恢復為質押中（已扣的款項加回餘額）

歸還資料包含在備份與還原中；資料庫自動升級到第 12 版。

## 注意
- 利息以「年利率 ÷ 365」按日計算，與實際銀行／券商的計息方式（例如按月、含頭不含尾）可能差幾元
- 目前一次歸還一整筆質押，不支援只歸還一部分
