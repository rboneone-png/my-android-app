# 股票記帳 1.0.0

第一個正式版本。下載下方的 `StockRecord-1.0.0.apk` 安裝；已安裝舊版的手機可以直接覆蓋安裝，資料會保留。

## 主要功能

- **交易與股利**：台股／美股買賣紀錄，台股手續費與證交稅自動計算；現金股利、配股、二代健保與美股預扣稅
- **持股總覽**：即時股價（自動刷新）、累積／未實現／已實現損益、股息收入、成本均／買均，庫存股可長按拖曳排序
- **觀察股票**：追蹤未持有的股票報價，可自訂順序
- **資產配置**：原型／正二／類現金／其他分類，總資產與曝險計算
- **質押**：利息支出、個股與整體維持率，三色警示與低於 175% 通知，可質押市值可切換包含正二
- **月報酬**：每日／每週／每月損益與報酬率月曆
- **股價通知**：漲跌幅、漲跌幅比率、股價高低於設定值，背景檢查
- **圖表與匯出**：持股比例圓餅圖、12 個月損益與股利長條圖、6 個工作表的 Excel
- **帳號與備份**：多帳號、密碼／指紋／臉部登入；備份到 Google 雲端硬碟、自動同步
