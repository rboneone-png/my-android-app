# 股票記帳 1.15.0

## 自動備份改成「寫入你選的檔案」，不再需要 Google Cloud 設定

- 設定頁的「雲端備份」→「自動備份」→「選擇自動備份檔案」：用系統的檔案畫面選一個位置（建議在「雲端硬碟」），App 會立刻寫入一次確認可用，之後依週期（1／6／12／24 小時）自動覆寫同一個檔案
- 不再使用 Google 授權（狀態碼 8 的問題不會再出現），也沒有 7 天過期；移除 Google 登入相關程式與設定教學
- 檔案被刪除或權限被收回時，會自動關閉自動備份並提示重新選擇
- 「立即備份」「從備份檔還原」改用這個檔案；手動「備份」「還原」按鈕不變

## 注意
- 以前連結 Google 的自動同步已停止，需要重新選一次備份檔
- 部分檔案提供者（含雲端硬碟）是否允許長期寫入，要看手機；若選檔後立即備份就失敗，畫面會顯示原因，請改選手機本機的檔案

## 安裝
直接覆蓋安裝，資料會保留。
