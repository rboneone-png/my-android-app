# 股票記帳 1.12.0

## 股利輸入改版

「發放日」後面新增兩個欄位，現金股利總額改為自動計算：

| 欄位 | 說明 |
|---|---|
| 每股股利 | 使用者輸入（台股元、美股美元）；沒有現金股利請留空 |
| 當天持有股股數 | 系統自動帶入：發放日當天持有的股數（依買賣紀錄，含當天買進與已入帳的配股） |
| 現金股利總額 | **= 每股股利 × 當天持有股股數**（自動計算，稅前），四捨五入到小數兩位 |

- 二代健保補充保費（台股單筆 2 萬元以上 2.11%）、美股預扣稅、實際入帳，都用算出的現金股利總額計算
- 發放日當天沒有持有這檔股票時，無法計算現金股利，會提示並無法儲存（只填配股股數不受影響）
- 改變發放日或買賣紀錄，持有股數與現金股利總額會跟著重算

## 舊紀錄
- 舊的股利紀錄沒有每股股利，編輯時會由現金股利總額反推顯示（例如 25,000 ÷ 33,333 股 ≈ 0.750008）
- 沒有改動每股股利與持股時，沿用原本的現金股利金額，不會被四捨五入的小誤差改掉
- 資料庫升級到 v10（股利新增每股股利欄位），備份與還原包含每股股利；舊備份檔仍可還原
