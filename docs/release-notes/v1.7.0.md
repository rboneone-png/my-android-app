# 股票記帳 1.7.0

## 新增「帳務」管理

持股總覽上方新增「帳務」按鈕（在「紀錄」旁），台股（台幣）與美股（美元）分開計算。

### 存入與領出現金
- 「存入現金」「領出現金」：輸入金額、日期（預設今天，年／月／日下拉選擇）、備註
- 下方列出所有存入與領出紀錄，點一筆可修改或刪除
- 紀錄包含在備份與還原中

### 顯示內容
| 項目 | 說明 |
|---|---|
| 當日賣出金額（B） | 今天所有賣出股票的成交金額總和 |
| 當日買進金額（C） | 今天所有買進股票的成交金額總和 |
| 當日帳務（D） | B − C |
| 當日可用餘額（A） | 存入現金 − 領出現金 + D（存入、領出為截至今天的累計） |

- 買賣金額為股數 × 成交價，不含手續費與證交稅
- 資料庫升級到 v9，舊資料會保留

## 安裝
直接覆蓋安裝，資料會保留。
