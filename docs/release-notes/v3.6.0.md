# 股票記帳 3.6.0

## 觀察：走勢圖

「觀察股票」「指數」「股票漲跌」每一檔的右側新增「**走勢**」按鈕，按一下展開走勢圖，再按收合。

- **K 線**：紅漲綠跌，疊上 MA5（橘）、MA20（藍）、MA60（紫）。
- **成交量**：台股用「張」、美股用「股」。
- **RSI(14)**：第三格指標，70、30 虛線（高於 70 偏熱、低於 30 偏冷）。
- **時間範圍**：3個月／6個月（預設）／1年。
- 點一下或左右拖曳圖面，上方顯示該日的日期、開高低收、成交量與 RSI。
- 剛分割完、Yahoo 歷史價只調整一部分的股票，會自動換成分割後的基準。
- 資料來源 Yahoo Finance，需要網路；同一檔 10 分鐘內不重複下載。
