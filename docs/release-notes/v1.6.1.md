# 股票記帳 1.6.1

## 持股日損益與月報酬今天的數字一致

**原因**：持股頁的「持股日損益」用即時報價（Google 財經）算，月報酬用 Yahoo 的歷史日線算（台股約延遲 20 分鐘），而且兩邊對當天買賣的處理不同，所以盤中數字對不上。

**改善**：
- 月報酬今天（最新一個交易日）的現價與前一日收盤，改用持股頁相同的即時報價；過去的日子仍用歷史收盤價
- 持股日損益改用月報酬相同的算式：今日市值 − 前一交易日市值 − 當天買進金額 + 當天賣出淨收入 + 當天入帳股利
- 兩邊用同一份報價、同一個函式計算，數字一定相同
- 月報酬頁看本月時，會依設定的秒數自動更新報價並重算今天的損益，不用再回持股頁更新

**影響**：今天有買進時，持股日損益會包含買進手續費（和月報酬一致）；今天有賣出時，會含賣出部分今天的漲跌。
