# 股票記帳 1.10.0

## 資產配置的現金改為帶入帳務管理

- 資產配置的「D. 現金」不再手動輸入，改為自動帶入帳務管理的**當日可用餘額**
  （存入現金 − 領出現金 + 帳務累計 + 質押金額累計 + 股利累計）
- 買賣、質押、股利、存入或領出現金後，資產配置的現金、總資產與各項比例會跟著更新
- 移除「修改現金」按鈕；要調整現金，請到持股總覽上方的「帳務」新增存入或領出
- 可用餘額為負數時，現金會以負數計入總資產

## 注意
- 以前在資產配置手動輸入的現金金額不再使用（備份檔仍保留該欄位）。若原本的現金還沒反映在帳務管理，請先到「帳務」用「存入現金」補記

## 安裝
直接覆蓋安裝，資料會保留。
