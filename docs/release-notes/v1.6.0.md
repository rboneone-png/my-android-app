# 股票記帳 1.6.0

## 質押設定新增「質押股數」與「維持率」

- **質押股數**（質押金額之前）：使用者輸入，須為 1,000 股的倍數，且不可超過可質押股數；選好股票後預設帶入全部可質押股數，可以改小
- **維持率**（質押金額之後）= 質押股數 × 股價 ÷ 質押金額 × 100%
  - 最低 166%，低於以紅色警示，且無法新增
  - 質押股數不合法時不顯示維持率
- 原本的質押率上限 60% 仍然有效，兩個條件都要符合才能新增
- 儲存的質押股數改為你輸入的股數（不再固定為全部可質押股數）
- 修改既有質押時，只有改動股數或金額才檢查上限
