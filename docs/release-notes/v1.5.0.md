# 股票記帳 1.5.0

## 新增質押流程改版

按質押頁的「新增質押」，先選股票、再設定。

### 選擇質押股票
- 清單欄位：股票、可質押股數、股價、可質押市值
- 可質押股數 = 持股 − 已質押股數，不足 1,000 股的零股不計（23,211 股只算 23,000 股）
- 扣除已質押後不足 1,000 股的股票不列入清單
- 可質押市值 = 可質押股數 × 股價
- 「包含正二」關閉時清單不含正二；清單上方也有同一個開關
- 點選股票進入質押設定

### 質押設定
- 股票代碼（可輸入）、股票名稱與股價自動帶入、可質押股數與可質押市值依清單算法帶入
- 質押金額須為 1,000 的倍數，不符時顯示錯誤說明請重新輸入（5,100、5,010、5,001 等）
- 質押利率（%）
- 質押率 = 質押金額 ÷ 可質押市值，最高 60%；超過以紅色警示並無法新增
- 利息預估 = 質押金額 × 質押利率（年）
- 日期預設今天，年／月／日下拉選擇

### 既有質押
- 點質押清單中的紀錄可修改金額、利率、日期，或刪除；股票與質押股數固定
- 既有紀錄不受影響；只有修改金額時才檢查 60% 上限

## 安裝
直接覆蓋安裝，資料會保留。
