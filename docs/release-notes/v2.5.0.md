# 股票記帳 2.5.0

## CLEC 退休投資策略：新增三項建議數值

依 J 現況建議配置，把 D 金融資產分成三項建議數值，顯示在 J 的下方：

- 建議指數ETF = 金融資產 × 原型%
- 建議正二ETF = 金融資產 × 正二%
- 建議類現金 = 金融資產 × 類現金%

例如金融資產 950 萬、J 為 433（原型 40%／正二 30%／類現金 30%）：建議指數ETF 380 萬、建議正二ETF 285 萬、建議類現金 285 萬。

- 金融資產 D 用的是目前的 F + G + H（含手動修改的數值）
- 顯示時四捨五入到整數，三項加起來可能與金融資產差 1～2 元；沒有輸入一年生活費時顯示 --
