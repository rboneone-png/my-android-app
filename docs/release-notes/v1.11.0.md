# 股票記帳 1.11.0

## 賣出股數不足時不能新增

- 新增或修改買賣時，逐日檢查股數：任何一天的賣出股數超過「之前持有 + 當天買進 + 配股」，
  就顯示紅字說明（例如「股數不足：2026-10-25 當日可賣 1,000 股，賣出合計 1,500 股，無法儲存」），
  「儲存」按鈕反灰，無法新增
- **補登過去日期的賣出**也會檢查：例如 1/1 買 1,000 股、3/1 再買 1,000 股，補登 2/1 賣 1,500 股，
  雖然現在總共持有 2,000 股，但 2/1 當天只有 1,000 股，會被擋下（舊版只看總持股，會漏掉）
- 這筆賣出若會讓之後某天的賣出不夠，也會擋下並說明是哪一天
- 修改既有買進的股數或日期、刪除買進，若會讓之後的賣出股數不足，同樣無法儲存或刪除，並說明原因
- 同一天先買再賣（當沖）可以；同一天的交易一律先算買進再算賣出，不受輸入順序影響
- 配股（股票股利）算在持股內，但要在賣出之前入帳才能賣

## 安裝
直接覆蓋安裝，資料會保留。既有紀錄不會被檢查或修改，只有新增或修改時才檢查。
