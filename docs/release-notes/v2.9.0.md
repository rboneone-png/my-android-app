# 股票記帳 2.9.0

## 新增「股票分割」

持股總覽右下角「＋」選單，在「新增股利」下方新增「股票分割」。

1. **選股票**：點「股票分割」後，先列出庫存股清單（台股、美股都有），選要分割的股票
2. **設定畫面**：
   - 股票：依你點選的股票帶入
   - 暫停交易日、恢復交易日：下拉選擇日期
   - 每股拆分：1 股分成幾股，例如 1 分 5，請輸入 5（2 以上的整數）
   - 暫停交易日必須早於恢復交易日，否則提示「設定錯誤：暫停交易日必須早於恢復交易日」，不能儲存
3. **自動分割調整**：到了恢復交易日，App 自動調整這檔股票在恢復交易日**之前**的資料
   - 買賣紀錄：股數 × 倍數、每股價格 ÷ 倍數（買賣金額、手續費不變）
   - 股利：配股股數 × 倍數、每股股利 ÷ 倍數（現金股利總額不變）
   - 質押：質押股數 × 倍數（質借金額不變）
   - 股價通知：股價／漲跌金額的門檻 ÷ 倍數（百分比門檻不變）
   - 每次打開 App、畫面刷新、背景檢查通知時都會確認；調整結果：持有股數變多、成本均價變低，總成本不變
4. 設定畫面下方的清單可看「待執行／已執行」；待執行的可修改或刪除；已執行的可「還原這次分割」調回分割前
5. 分割資料包含在備份與還原中；資料庫自動升級到第 13 版

## 注意
- 恢復交易日是「到了就調整」，開盤前報價可能還是分割前的價格，開盤後更新股價就會正常
- 恢復交易日當天或之後輸入的買賣，請直接輸入分割後的股數與價格
- 目前只支援「拆分」（1 變多），不支援反向分割（合併）

## 安裝
直接覆蓋安裝，資料會保留。
