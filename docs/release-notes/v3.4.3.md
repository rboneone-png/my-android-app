# 股票記帳 3.4.3

## 質押：分割後質押股數不一致，可質押市值算錯

分割已執行，但質押股數沒有跟著調整（還原備份、補登分割前的資料後會發生），或被重複調整時，「可質押股數」＝持股 − 已質押股數 就會算錯，可質押市值也跟著錯。

- 每次開 App、還原備份、新增買賣之後，會自動逐筆檢查已執行分割前的質押：
  - 質押股數比當天持股還多（被多調整）→ 自動 ÷ 倍數。
  - 質押股數還是分割前的（用「質押股數 × 當天收盤價 ÷ 質借金額」明顯低於最低維持率判斷）→ 自動 × 倍數。
- 質借金額不變；不確定時（例如沒網路抓不到歷史價）不會更動，下次再檢查。
- 另外，自動修復買賣時重新執行分割，不再連動質押股數（質押改由上面的逐筆檢查處理），避免質押被重複調整。
