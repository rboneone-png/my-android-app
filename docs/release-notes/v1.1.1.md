# 股票記帳 1.1.1

## 通知條件文字修正

| 原本 | 修正後 |
|---|---|
| 股價漲幅大於等於設定值 | 股價上漲達到設定金額 |
| 股價跌幅大於等於設定值 | 股價下跌達到設定金額 |
| 股價漲幅比率大於等於設定值 | 股價上漲達到設定比例 |
| 股價跌幅比率大於等於設定值 | 股價下跌達到設定比例 |
| 股價高於等於設定值 | 股價上漲至設定價 |
| 股價低於等於設定值 | 股價下跌至設定價 |

- 「上漲」以紅色、「下跌」以綠色顯示（下拉選單、通知清單、說明文字）
- 通知清單的條件也改用相同字詞，例如「上漲達 50 元」、「下跌至 2200 元」
- 判斷方式不變，已設定的通知不需重設
