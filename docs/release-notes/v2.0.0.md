# 股票記帳 2.0.0（正式版）

2.0.0 是正式版，功能與 1.16.0 相同，只調整版本號。從 1.0.0 到現在的主要功能：

- 多帳號登入（密碼／指紋／臉部），可用備份檔在新手機登入原帳號
- 持股總覽（台股／美股）、買賣與股利紀錄、即時損益（Google Finance 報價）
- 帳務管理：存入／領出現金、當日賣出／買進／質借金額／股利、可用餘額
- 月報酬日曆與資產走勢圖
- 資產配置、質押（質借）管理與維持率通知
- 觀察清單、市場指數、股票漲跌（相對 2 年最高價）、價格通知
- 備份與還原；自動備份寫入你選的檔案（可放 Google 雲端硬碟），週期可自訂

## 安裝
直接覆蓋安裝，資料會保留（簽章金鑰不變）。
