# 股票記帳 1.16.0

## 自動備份週期可自訂

- 原本的 1／6／12／24 小時選項，改成自己輸入「天」與「小時」，預設 0 天 24 小時
- 輸入後按「套用」才生效；合計至少 1 小時，最多 365 天
- 原本選的週期會保留（例如原本選 6 小時，會顯示 0 天 6 小時）

## 名稱修改
- 資產配置：「D. 現金（帳務可用餘額）」改為「D. 現金」（下方說明文字仍註明來源是帳務的當日可用餘額）
- 質押：「質押金額」改為「質借金額」、「質押總金額」改為「質借總金額」。畫面、通知、Excel 匯出、說明文字一律更新（包含帳務頁的「當日質借金額」「質借金額累計」）

## 質押清單預設收合
- 質押清單依月份分組，進入頁面時預設全部收合，點月份才展開

## 安裝
直接覆蓋安裝，資料會保留。
