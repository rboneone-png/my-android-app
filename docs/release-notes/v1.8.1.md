# 股票記帳 1.8.1

## 修正：帳務管理隔天餘額只剩現金

**問題**：當日可用餘額只計算「今天」的買賣與質押，所以當天餘額正確，到了隔天，前一天的買賣與質押就消失，只剩存入與領出的現金。

**修正**：當日可用餘額改為歷來累計：
當日可用餘額 = 存入現金 − 領出現金 + **帳務累計** + **質押金額累計**

- 帳務累計 = 歷來每一天（賣出 − 買進）的總和；今天的部分就是「當日帳務」
- 質押金額累計 = 歷來質押金額的總和
- 前幾天的買賣與質押會一直留在餘額裡，沒有新交易的日子餘額不變
- 「當日賣出金額／買進金額／帳務／質押金額」仍只顯示今天的數字，下方新增「帳務累計」「質押金額累計」兩列
- 過去的美股買賣用目前匯率換算成台幣（沒有保存每天的匯率）
