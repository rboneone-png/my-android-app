# 股票記帳 2.10.0

## 設定的「匯出 Excel」改為「匯出／匯入 Excel」，新增匯入

**匯入 Excel**（設定 → 匯出／匯入 Excel → 匯入 Excel）：

- 讀取「**交易紀錄**」「**股利**」兩個工作表（格式同匯出）。依標題列的名稱對應欄位，所以欄位順序可以不同、選填欄位可以省略
  - 交易紀錄必要欄位：日期、市場、代號、買賣、股數、成交價；選填：名稱、手續費、交易稅、稅別、備註
  - 股利必要欄位：發放日、市場、代號，且「現金股利」或「配股股數」至少填一項；選填：名稱、扣稅／健保、匯費、備註
- **手續費、交易稅、股利扣稅留空時，依設定頁的費率自動計算**；明確填 0 就是 0
- 日期可用 2026-11-10、2026/11/10、20261110 或 Excel 的日期格式；市場填「台股」「美股」；買賣填「買進」「賣出」；Excel 把台股代號 0050 存成數字 50 時，自動補回 0050
- 讀完先顯示摘要：讀到幾筆買賣、幾筆股利，以及讀不懂的列（含工作表與列號、原因），這些列不會匯入
- 兩種匯入方式：
  - **新增**：加到現有資料；和現有紀錄完全相同的會略過，所以同一個檔案匯入兩次不會重複
  - **取代現有資料**：先刪除目前所有買賣與股利再匯入（會再確認一次）
- 匯入後如果某檔股票賣出超過持有股數（例如檔案裡缺了買進紀錄），**整批不匯入**並說明是哪一檔、哪一天

**匯出**：交易紀錄工作表最後多一欄「稅別」（一般／ETF／當沖，台股才有），讓匯出再匯入時能還原稅別。

## 注意
- 持股、已實現損益、每月損益、質押這幾個工作表是計算結果，匯入時不讀；質押與其他設定請用「雲端備份」
- 匯入的買賣不會自動查股票名稱（沒填名稱就用代號），之後可到紀錄裡修改
- 建議先「匯出」一次當範本，改完再匯入；要「取代」之前先備份
