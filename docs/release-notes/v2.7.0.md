# 股票記帳 2.7.0

## 整體介面優化

- **新配色**：固定的品牌配色（深藍為主色），不再隨手機桌布變色；淺色與深色模式各有一組。頁面是淡灰藍底，內容放在白色圓角卡片上，層次更清楚
- **頂欄**：淡藍底、深藍粗體標題，狀態列與頂欄同色
- **摘要卡**：持股總覽、資產配置、質押、帳務管理的摘要改成淡藍漸層的圓角卡片（持股總覽的累積損益原本沒有卡片）
- **列表**：庫存股、觀察、月曆格子改成白底，和頁面背景分開；分組標題的色條加圓角
- **按鈕**：主要按鈕與「＋」「新增…」浮動按鈕改為深藍；次要動作（例如「質借歸還」）維持淡藍
- **字型**：標題加粗；金額與百分比使用等寬數字，上下對齊更整齊
- **圓角**：卡片、輸入框、對話框的圓角加大，陰影變輕
- **登入頁**：鎖頭放進圓形淡藍徽章
- 紅漲綠跌、質押維持率的紅黃綠顏色都不變；所有功能與數字不變
