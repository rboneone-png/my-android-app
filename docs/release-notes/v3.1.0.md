# 股票記帳 3.1.0

## 修正：可用餘額每次打開會變動

**原因**：以前帳務管理把美股買賣與美股股利，全部用「現在最新的美元兌台幣匯率」換成台幣，連歷來的交易也一起重算，所以每次打開 App、匯率更新，可用餘額就跟著變。

**改法**：美股的每一筆買賣、每一筆股利，各自記下**當時的匯率**，之後都用那個匯率換算，匯率每天變動不會再改動餘額。

- 新增或編輯美股買賣、股利時，多一個「**匯率（美元兌台幣）**」欄位：預設依日期自動帶入（今天用目前匯率、過去的日期抓當日收盤匯率），可以改成券商實際的匯率，按「自動」恢復
- **舊紀錄**（升級前建立的、Excel 匯入的）原本沒有匯率，App 會在背景自動抓每筆**當天的歷史匯率**補上（需要網路，假日用前一個交易日）；補上之前暫時用目前匯率，抓不到的下次開啟再補
- 補上之後，餘額就固定了。**第一次補完時，餘額可能會跳一次**（因為從「目前匯率」換成「各筆當時的匯率」），之後不會再因為匯率變動
- 匯率也包含在備份與還原，以及 Excel 匯出（「交易紀錄」「股利」多一欄「匯率」）；匯入 Excel 時匯率欄選填，留空由 App 補
- 帳務管理頁底部的提示文字改為「各筆交易當時的匯率」

## 注意

- 台股不受影響
- 資產配置、持股市值等「現值」仍用目前匯率（那是現在值多少錢，本來就該跟著匯率走）
- 歷史匯率來自 Yahoo Finance 的日線收盤價，可能和券商實際成交匯率有些差距，可以逐筆手動修改
- 資料庫升級到 v14（新增欄位），升級後不能降回舊版本
