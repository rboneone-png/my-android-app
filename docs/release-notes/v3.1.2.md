# 股票記帳 3.1.2

## 修正：股票分割後，月報酬的損益被放大成倍數

**現象**：股票做了分割（例如 00662 在 11/17 恢復交易、1 分 5），打開 App 執行分割後，月報酬裡分割前那些日子的損益變得明顯偏大。

**原因**：分割時 App 會把恢復交易日之前的股數 × 倍數；但月報酬用 Yahoo 的歷史收盤價算市值，而剛分割的前幾天，Yahoo 的歷史價往往還沒依分割調整（仍是分割前的高價）。於是「股數已經乘過倍數、價格還是舊的」，每一天的市值與損益都被放大成倍數。

**修正**：
- 計算月報酬與資產走勢時，自動檢查 Yahoo 的歷史價有沒有依這次分割調整過（比對恢復交易日前後的價格）
- 發現沒調整，就自己把恢復交易日之前的價格 ÷ 倍數，再和股數對齊；Yahoo 之後調整完畢，就自動沿用 Yahoo 的資料
- 查不到比較基準時（例如恢復交易日還沒有任何報價），照 Yahoo 的資料計算

## 注意

- 持股總覽的庫存股、今日損益只用即時報價，不受這個問題影響
- 這個修正只處理「股數已調整、歷史價沒調整」的情況
