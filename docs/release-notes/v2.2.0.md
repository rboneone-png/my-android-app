# 股票記帳 2.2.0

## 帳務管理新增「貸款」，繳款日自動扣款

**新增貸款**（帳務頁的「新增貸款」按鈕）：
- A. 貸款型式：房貸、信貸、車貸、其他（另有選填的名稱／備註）
- B. 貸款金額：自己輸入
- C. 利率：自己輸入，單位 %（年利率）
- D. 貸款期數：自己輸入（每月一期，例如 20 年 = 240 期）
- E. 已繳期數：預設 0
- F. 每月繳款：系統自動計算（本息平均攤還，每月固定金額，四捨五入到整數）
- G. 繳款日：每月幾號（1～31 日）

**自動扣款**：
- 帳務頁新增「當日貸款金額」：今天是繳款日時，自動從「當日可用餘額」扣掉當月的繳款
- 扣過的款項會累計在「貸款累計」，隔天不會消失；當日可用餘額 = 存入 − 領出 + 帳務累計 + 質借金額累計 + 股利累計 − 貸款累計
- 從建立貸款那天「之後」的第一個繳款日開始扣；繳滿期數後停止
- 該月沒有那一天（例如繳款日 31 日、遇到 2 月）改在當月最後一天扣
- 資產配置的「D. 現金」就是當日可用餘額，會跟著扣掉貸款

**貸款清單**：帳務頁的「貸款」可展開／收合（預設收合），顯示型式、金額、利率、已繳／總期數、每月繳款與下次繳款日；點一筆可修改或刪除。貸款資料會包含在備份與還原中。

## 注意
- 每月繳款假設「每期金額相同」，最後一期不做尾差調整
- 「已繳期數」是建立貸款時已經繳過的期數，之後每個繳款日自動再加一期；修改貸款時，扣款會依新的設定從建立日起重新計算
- 刪除貸款時，這筆貸款已經扣掉的款項會一起加回可用餘額

## 安裝
直接覆蓋安裝，資料會保留（資料庫自動升級到第 11 版）。
