# 股票記帳 1.3.0

## 觀察可加入大盤指數

新增觀察（或股票漲跌設定）時，選「指數」即可從清單加入：

| 指數 | 市場 |
|---|---|
| 台灣加權指數 | 台股 |
| S&P 500 | 美股 |
| 道瓊工業指數 | 美股 |
| 那斯達克綜合指數 | 美股 |
| 那斯達克 100 指數 | 美股 |
| 費城半導體指數 | 美股 |

- 指數點數由 Google 財經即時提供，抓不到時改用 Yahoo Finance
- 顯示點數、漲跌、漲跌幅；在「股票漲跌」中可看指數距離 2 年高點的比例
- 指數同樣可以拖曳排序、點一下移除，並包含在備份中
