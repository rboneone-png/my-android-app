# 股票記帳 3.1.7

## 分割後買賣沒調整到：改成全自動修復，移除「重新執行調整」按鈕

3.1.6 加的「重新執行調整」按鈕，按錯會把股數重複調整，太危險，已經**移除**，改成自動處理。

**自動修復怎麼做**
- 對每一筆「已執行」的分割，抓那檔股票的歷史收盤價（Yahoo 沒調整到的部分先自己對齊成分割後的價格）
- 把恢復交易日之前的每一筆買賣，拿**買賣價格**和**同一天的收盤價**比：
  - 價格接近當天收盤價 → 已經調整過，不動
  - 價格是當天收盤價的將近一個倍數 → 還是分割前的原價，自動調整這一筆（股數 × 倍數、價格 ÷ 倍數）
- 如果這檔股票分割前的買賣**全部**都還是原價，就整筆分割重新執行一次（連同股利、質押股數、通知價格）
- 買賣價格和當天收盤價相差不會太大，所以不會把已經調整好的資料誤判；找不到那天的收盤價、或抓不到歷史價（沒網路）時，什麼都不改，下次再檢查
- 重複檢查不會重複調整

**什麼時候會檢查**
- 每次打開 App、儲存買賣之後、還原備份之後、匯入 Excel 之後

**會修好什麼**
- 分割後還原了分割前的備份，結果股數、成本均還是分割前的數字（例如 00662 變成 4,000 股、成本均 109.50）→ 打開 App（需要網路）會自動變成 20,000 股、成本均約 21.9
- 分割後才補登分割前的買賣，用原股數與原價格輸入就好，會自動調整

## 注意

- 需要網路；沒有網路時不會動資料，連上網路後再打開 App 就會修
- 分割紀錄本身不見了（例如換新手機）的情況，請到「股票分割」重新設定一次
