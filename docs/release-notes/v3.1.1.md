# 股票記帳 3.1.1

## 修正：可用餘額每次打開還是會變動

**原因**：3.1.0 要幫舊的美股紀錄補上「當天的歷史匯率」，但抓歷史匯率的程式把「成交量為 0」的資料當成休市日全部丟掉。匯率資料的成交量永遠是 0，所以整份匯率資料都被丟掉，舊紀錄補不到匯率，帳務就繼續用「目前匯率」換算，餘額才會每次打開都變動。

**修正**：
- 匯率改用專用的解析方式：不再用成交量判斷休市，並依匯率日線的時間點（倫敦午夜）換算成正確的日期
- 新增、編輯美股買賣與股利時，過去日期的匯率也能正確自動帶入
- 升級後打開 App（需要網路），會自動補上舊紀錄「當天」的匯率；補上之後餘額就固定了

## 注意

- 3.1.0 期間，若有「發生在最近 10 天內」的舊美股紀錄被補到匯率，那個匯率可能是補的當下的匯率（不是交易當天的）；差異很小，也可以打開那筆紀錄手動修改匯率
- 補完歷史匯率後餘額可能再跳一次，之後不會再因匯率變動
- 補匯率需要連網；沒連網時舊紀錄暫時仍用目前匯率，下次連網時會再補
