# 股票記帳 3.1.6

## 新增：分割「已執行」但買賣沒調整到時，可以重新執行調整

**起因**：還原備份之後，00662 的分割顯示「已執行」，但持股總覽的 00662 仍是分割前的數字（4,000 股、成本均 109.50），現價卻是分割後的 23.10，市值與損益全部失真，月報酬也跟著出現落差。這時「分割紀錄」與「買賣資料」的狀態對不上，而原本沒有辦法重新執行一次分割（「還原這次分割」會先把股數再除一次，反而更糟）。

**新增**：
- 點進一筆**已執行**的分割，最下面新增「**重新執行調整**」：把買賣、股利、質押股數與通知價格，再依這筆分割調整一次（股數 × 倍數、價格 ÷ 倍數）
- App 會自動偵測：已執行的分割，如果恢復交易日之前的買賣平均價格還在分割前的水準（約為現價的一個倍數），就在畫面上用紅字提醒「買賣可能沒有調整到」
- 按下前會跳出確認：**只有持股總覽的股數與成本均還是分割前的數字時才要按**；資料若已經是分割後的，按了會重複調整

## 怎麼修你的 00662

1. 安裝 3.1.6，到「持股總覽 →「＋」→ 股票分割」
2. 點「已設定的股票分割」裡 00662 那筆（已執行）
3. 看到紅字提醒、且持股總覽的 00662 還是 4,000 股、成本均約 109.5 時，按「重新執行調整」→ 確認
4. 回到持股總覽：00662 應變成 20,000 股、成本均約 21.9，總成本不變；月報酬也會恢復正常
