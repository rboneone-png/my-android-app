# 股票記帳 2.1.1

## 通知條件改用股票常用語

| 原文 | 新用語 |
|---|---|
| 股價上漲達到設定金額 | 漲幅 ≥ X 元 |
| 股價下跌達到設定金額 | 跌幅 ≥ X 元 |
| 股價上漲達到設定比例 | 漲幅 ≥ X% |
| 股價下跌達到設定比例 | 跌幅 ≥ X% |
| 股價上漲至設定價 | 漲到 X 元（突破價） |
| 股價下跌至設定價 | 跌到 X 元（跌破價） |

- 通知設定的下拉選單、通知清單、手機收到的通知標題、輸入欄下方說明文字都一併更新（例如「漲幅 ≥ 50 元」「漲到 2500 元（突破價）」）
- 「漲幅」「漲到」仍是紅色，「跌幅」「跌到」仍是綠色
- 已設定好的通知不受影響，只是顯示的文字變了
