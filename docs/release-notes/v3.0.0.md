# 股票記帳 3.0.0

## 股票漲跌：每檔可展開技術點

觀察 → 「股票漲跌」分頁：

- 每一檔股票**點一下展開／收合**，**預設收合**；標題列右側的箭頭表示目前狀態
- 展開後顯示「技術點」表格：

  | 技術點 | 下跌百分比 | 股價 |
  |---|---|---|
  | P1 | 10% | 2 年最高點 × (1 − 10%) |
  | P2 | 20% | 2 年最高點 × (1 − 20%) |
  | P3 | 30% | 2 年最高點 × (1 − 30%) |
  | P4 | 40% | 2 年最高點 × (1 − 40%) |
  | P5 | 50% | 2 年最高點 × (1 − 50%) |

- 「2 年最高點」就是列表上的 2 年最高價；盤中現價創新高時，以現價計算
- 還沒抓到 2 年最高價時，展開會提示「還沒有 2 年最高價」
- 原本「點一下移除」改為：展開後按下方的「移除這檔」（因為點一下現在是展開／收合）
- 長按拖曳排序不變
