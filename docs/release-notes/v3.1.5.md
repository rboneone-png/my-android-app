# 股票記帳 3.1.5

## 股票分割：標示已設定的分割，並防止重複設定

**起因**：還原備份後，00662 的分割已經是「已執行」，但在「選擇要分割的庫存股」清單裡，00662 還是會出現——因為這個清單列的是**所有庫存股**，不管有沒有設定過分割。這樣容易讓人誤以為還沒分割，甚至再設定一次（會把股數重複調整）。

**改進**：
- 清單裡，已經設定過分割的股票，名稱下方會標示「已設定分割：1 分 5・恢復 2026-11-17（已執行）」
- 清單上方加一行說明：這裡列出所有庫存股
- **同一檔股票、同一個恢復交易日不能重複設定**：重複設定時會提示「已經有分割設定了」，不能儲存
- 其餘行為不變
