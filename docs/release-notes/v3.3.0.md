# 股票記帳 3.3.0

## 配置分頁

- 「CLEC退休投資策略」改名為「**CLEC投資策略**」。
- 新增「**加減碼策略**」分頁（資產配置 → 第三個標籤，也可左右滑動切換）：
  - A 投入資金 = 持股成本；B 持股市值（皆台幣，不含現金）。
  - C 配置方式：與 CLEC 相同的選項，可自行選擇。
  - D 預留生活費：自行輸入，說明「尚在工作建議3~6個月，退休3年以上」。
  - E 策略 VS 實際：原型、正二、類現金／現金的「實際佔比」對照「策略佔比、策略金額（投入資金 × 策略佔比）」。
  - F 加碼設定：輸入加碼等份 a，每次加碼金額 = (A × 0.3 − D) ÷ a。
  - G 減碼策略：加碼每漲回 10%，賣出加碼金的 10% 放回類現金，直到全部取回；顯示每次賣出金額。
- 加減碼的設定會一併備份與雲端同步。
