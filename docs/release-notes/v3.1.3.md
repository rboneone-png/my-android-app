# 股票記帳 3.1.3

## 修正：股票分割後，月報酬在「分割前有買進」的日子仍然錯誤

**怎麼找到的**：用 00662（1 分 5）的 Yahoo 真實歷史資料查證。Yahoo 對剛分割的股票，**只調整了最近兩個交易日**的價格（11/9、11/10，價格已 ÷ 5、成交量 × 5），更早的日子（11/6 以前）還是分割前的原價（約 113～119）。

**3.1.2 為什麼沒修好**：3.1.2 只比對「恢復交易日前最後一個交易日」的價格，看到那一天已經調整過，就以為整份歷史價都調整好了，沒有處理更早、仍是原價的日子。這些日子的市值（股數已 × 5、價格還是原價）被放大成 5 倍，**分割前有買進的那天**，當天損益就會嚴重失真（前一天持股市值被放大 5 倍，扣掉去）；沒買進的日子只是持股的漲跌被放大，不容易看出來。

**修正**：
- 不再只比對恢復交易日前一天，而是在恢復交易日前後的價格裡，找出「連續兩個交易日價格相差約一個倍數」的斷層，斷層之前沒調整到的價格全部 ÷ 倍數
- 不管 Yahoo 是完全沒調整、只調整一部分，或已經完整調整，都能正確對齊；完整調整後直接沿用 Yahoo 的資料
- 一般交易日的漲跌幅（跌停 −10%、大跌 30%）遠小於一個倍數的斷層，不會被誤判
- 月報酬與資產走勢兩處都套用

## 注意

- 持股總覽的庫存股、今日損益只用即時報價，不受影響
- 若某天顯示的數字還是不對，請告訴我日期與你自己算的結果
