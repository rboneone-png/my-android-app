# 股票記帳 1.8.0

## 帳務管理調整

1. **存入與領出紀錄可展開／收合**，預設收合（標題顯示筆數）
2. **當日可用餘額公式變更**：
   當日可用餘額 = 存入現金 − 領出現金 + 當日帳務 + **當日質押金額**
   - 當日質押金額 = 今天新增的質押金額（日期為今天的質押）
3. **不再分台股、美股，統合為同一個新台幣帳戶**：
   - 存入、領出都以新台幣記帳
   - 當日賣出、買進金額含台股與美股，美股以當日匯率（美元兌台幣即時匯率）換算成台幣
   - 畫面會顯示使用的匯率；尚未取得匯率時，會提示今天的美股買賣未計入
   - 所有金額小數點四捨五入到整數（每筆買賣各自四捨五入後加總）

## 注意
- 1.7.0 時若有以「美股」記下的存入／領出紀錄，現在一律視為新台幣金額，請檢查是否需要修改
