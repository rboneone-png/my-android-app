## 資產配置新增「CLEC退休投資策略」分頁

資產配置頁頂端分成「資產配置」與「CLEC退休投資策略」兩個分頁。CLEC 分頁：

| 編號 | 項目 | 內容 |
|---|---|---|
| A | 一年生活費 | 自己輸入 |
| B | 配置方式 | 下拉選單，只能選：703、613、523、433、343、253、163、073 |
| C | 曝險（Beta） | 第一碼數值 + 2 × 第二碼數值 |
| D | 金融資產 | F + G + H |
| E | 曝險金額 | 資產配置頁的曝險金額 |
| F | 指數ETF | 資產配置頁的原型市值 |
| G | 正二ETF | 資產配置頁的正二市值 |
| H | 類現金 | 類現金市值 + 現金 |
| I | 幾倍年生活費 | D ÷ A，小數一位（第二位四捨五入） |
| J | 現況建議配置 | 依 I 對照「N 年生活費」表 |

- 配置三碼依序是 原型指數：正二槓桿：類現金（各碼是幾成），例如 703 = 70% 原型、0% 正二、30% 類現金
- 對照表：>50 → 703、40～50 → 613、30～40 → 523、20～30 → 433、16～20 → 343、13～16 → 253、10～13 → 163、<10 → 073；目前落在哪一列就標黃色
- 邊界：剛好 50 年算 40～50；其餘區間含下限（剛好 30 年算 30～40）
- 一年生活費與配置方式會包含在備份與還原中
