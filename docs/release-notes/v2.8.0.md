# 股票記帳 2.8.0

## 設定新增「配色模式」

- 設定 → 配色模式：「淺色模式」「深色模式」兩種配色，**預設淺色模式**，選了馬上生效，登入頁也會套用
- 不再跟著手機的系統深色設定，完全由這個選項決定；狀態列與導覽列的圖示顏色會一起切換
- 這個選項是整個 App 共用（換帳號也一樣），不包含在備份裡

## 通知移進設定

- 底部導覽列不再有「通知」，改在設定頁新增「股價通知」項目（顯示目前有幾筆條件），點進去就是原本的通知清單與新增／編輯畫面，左上角有返回鍵

## 帳務移到底部導覽列

- 帳務管理放到原本通知的位置（導覽列由左到右：持股、觀察、配置、質押、月報酬、帳務、設定），持股總覽上方不再有「帳務」按鈕

## 安裝
直接覆蓋安裝，資料會保留。注意：如果你的手機原本是深色模式，更新後會變成淺色模式，要深色請到設定 → 配色模式切換。
