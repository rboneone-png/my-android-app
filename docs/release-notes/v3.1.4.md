# 股票記帳 3.1.4

## 修正：分割前做的備份，在分割後還原會異常

**原因**：還原備份會用備份的內容取代手機上所有資料，包含「股票分割」的設定。如果備份是在分割之前做的：
- 備份裡的買賣還是**分割前**的股數與價格
- 備份裡沒有這筆分割的設定（或設定還沒執行）
- 還原後，股數與價格對不上分割後的股價，持股、損益、月報酬全部異常

**修正**：
- 還原時，手機上「備份裡沒有」的股票分割會保留下來，並標成還沒執行
- 還原完成後，立刻依到期的分割自動調整買賣的股數與價格（不用等下次更新報價）
- 備份裡本來就有的分割不受影響：備份是分割後做的（已執行），買賣本來就是分割後的，不會重複調整

## 注意

- 只會保留「手機上現有」的分割。如果是換新手機、重裝後用備份檔登入，新手機上沒有分割紀錄，請到 持股總覽 →「＋」→「股票分割」重新設定一次（恢復交易日已過的話，會馬上調整）
- Excel「取代」匯入也一樣：匯入的買賣若是分割前匯出的，不會自動調整
