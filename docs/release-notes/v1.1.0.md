# 股票記帳 1.1.0

## 新功能

### 質押清單依月份分組
- 依質押日期的月份分組，新的月份在前
- 點月份列可展開或收合
- 月份列顯示該月的筆數、利息、質押金額與維持率（依三色規則變色）

### 觀察頁新增「股票漲跌」分頁
- 觀察頁分成「觀察股票」與「股票漲跌」兩個分頁，觀察股票維持原樣
- 股票漲跌：按「新增設定」加入股票，顯示 2年最高價、現價、漲跌幅
  - 最高價為近 2 年的最高股價，自動從網路抓取並標示日期，每天更新一次
  - 盤中創新高時以現價為最高價，並標示「創新高」
  - 漲跌幅 = 現價 ÷ 最高價 × 100%
- 長按拖曳調整順序，點一下移除；清單會一起備份與還原

## 安裝
直接覆蓋安裝 1.0.0，資料會保留。
