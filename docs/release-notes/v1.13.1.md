# 股票記帳 1.13.1

## 修正 Google 自動雲端同步

- 授權失效（例如 Google Cloud 還在「測試中」約 7 天過期）時，背景備份原本會一直默默重試、畫面仍顯示「已連結」；現在會把開關關回去並顯示「Google 授權已失效，請重新連結」，重新開啟自動同步即可
- 上傳遇到 token 過期（401）時，會自動重新取得一次再試
- 背景備份遇到網路問題最多重試 3 次，下個週期再自動執行，不再無限重試
- 連結失敗時的錯誤訊息改成看得懂的說明（例如「Google 不認得這個 App」要檢查套件名稱與 SHA-1、「連不上 Google 服務」）

## 安裝
直接覆蓋安裝，資料會保留。需重新連結一次 Google 帳號。
